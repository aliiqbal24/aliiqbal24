# Hi, I'm Ali.

I'm a University of Alberta student who likes following an interesting question all the way to working software.

Sometimes that means a neural network steering a spaceship. Sometimes it's a workout companion, a data reliability tool, or a game about robots taking a missing lunch much too seriously. I enjoy moving between the mathematics, the engineering, and the experience of using what I build.
